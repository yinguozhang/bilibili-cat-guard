# B站橘猫守护 · v0.5.0

一个温柔但不容易被忽略的 Chrome MV3 扩展。

当你在 B 站的一轮使用达到设定时长后，页面会被暖色半透明遮罩覆盖，视频 / 音频暂停。戴眼镜橘猫会请你明确做一次选择：

- **再看 10 分钟**：恢复页面和原本正在播放的媒体，10 分钟后橘猫再次出现；
- **好，这就去写论文**：关闭当前 B 站标签页，并结束这一轮。

设计原则：**温柔 + 坚定 + 最后的决定仍然属于用户。**

## 安装

还没有上架 Chrome 应用商店，需要用开发者模式加载：

1. 下载本仓库（右上角 `Code` → `Download ZIP`），解压到本地任意位置；
2. Chrome 地址栏打开 `chrome://extensions/`；
3. 右上角打开 **开发者模式**；
4. 点 **加载已解压的扩展程序**，选择解压后的**根目录**（即包含 `manifest.json` 的那一层，不要选到 `assets` 或 `icons` 里）；
5. 点工具栏的拼图图标，把橘猫**固定**到工具栏；
6. **打开 B 站页面并按 F5 刷新一次** —— 已经打开的页面不会自动注入，不刷新橘猫出不来；
7. 点工具栏橘猫图标，选一个提醒阈值。

想先看看橘猫长什么样、不想装扩展：直接双击根目录的 `preview.html`。

两个常见疑问：

- **浏览器每次启动弹「请停用开发者模式扩展程序」**：这是开发者模式的正常提示，点「取消」保留即可，不是扩展报错。
- **能打包成 .crx 发给别人吗**：Chrome 现在只信任商店安装的 crx，本地打包的会被自动禁用。分享方式就是让对方下载解压后按上面步骤加载。

## 当前交互

### 首次提醒

popup 可选择：

- 5 分钟
- 15 分钟
- 30 分钟
- 45 分钟
- 60 分钟

达到首次阈值后，橘猫覆盖整个 B 站页面。遮罩保留原页面轮廓，但视频内容被弱化且不可继续操作。

### 再次提醒

“再看 10 分钟”是固定产品规则，不额外增加设置项。

用户每次选择继续后，从点击按钮的时刻重新计算 10 分钟；10 分钟后再次出现全屏橘猫。提醒次数没有人为上限。

### 一轮 B 站使用

- 换视频：继续累计；
- 新开 / 切换到另一个 B 站标签：继续累计；
- 切到其他网站或其他应用：暂停；
- 5 分钟内回到 B 站：接着这一轮；
- 连续离开 B 站达到 5 分钟：本轮结束；
- 全屏橘猫正在等待选择：暂停计时；
- 选择离开：关闭当前 B 站标签并结束本轮。

## 三阶段图片橘猫

角色素材全部是扩展本地透明 PNG，不联网加载：

- `assets/cat-gentle.png`：第一次提醒；
- `assets/cat-sleepy.png`：第二次提醒；
- `assets/cat-serious.png`：第三次及以后。

三种状态使用同一套角色设计。代码只负责选择图片、文案、动画和交互，不再用 SVG 几何图形画猫。

## 今日记录

popup 会显示：

- 今天在 B 站的累计使用时长；
- 今天橘猫出现次数；
- 今天选择“再看 10 分钟”的次数；
- 今天选择离开的次数。

今日记录按照浏览器本地日期自动切日。首次从旧版本升级到 v0.5.0 时，今日记录从升级后的实际使用开始累计，不会把过去的累计记录伪装成今天的数据。

旧版累计 `stats` 仍保留在本地存储中用于兼容，但当前 popup 不展示复杂历史报表。

## 安全预览

popup 中可以选择：

- 第一次
- 第二次
- 第三次+

然后点击 **立刻召唤橘猫试试**。

预览模式：

- 不修改真实计时；
- 不计入今日记录；
- 不关闭标签；
- 两个按钮都只关闭预览。

根目录 `preview.html` 也可直接用于视觉预览。

## 正式图标

工具栏图标直接从当前图片橘猫提炼，保持圆眼镜、橘色毛发和暖米色背景：

## 数据与权限

数据全部保存在 `chrome.storage.local`：

- 不上传服务器；
- 不需要账号；
- 不跨设备同步。

权限：

- `storage`：保存设置、会话状态和今日记录；
- `tabs`：识别当前 B 站标签、在用户选择离开时关闭当前标签；
- `alarms`：MV3 service worker 周期计时；
- `scripting`：扩展重载后为旧 B 站页面补注入脚本和 CSS。

站点权限仅匹配 `*.bilibili.com`。

## v0.5.0 重点

这一版不改变已经验证好的全屏提醒机制，主要增加两件事：

1. **今日记录**：开始回答“橘猫有没有真的帮我少刷 B 站”；
2. **正式图标**：让图片橘猫成为扩展在 Chrome 工具栏里的统一识别形象。

下一阶段建议先真实使用 3～7 天，再决定是否需要 7 天趋势，而不是立即增加更多功能。
